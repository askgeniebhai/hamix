# docs/

of the top-level governance files (`README.md`, `PROJECT_CONSTITUTION.md`,
`ARCHITECTURE.md`, `MILESTONES.md`, `VALIDATION.md`, `SECURITY.md`,
`DECISIONS.md`).

Empty as of Milestone 0 — populated as future milestones produce
documentation worth keeping (e.g. API references, ADRs too detailed for
`DECISIONS.md`, onboarding notes).
